SOLEMART — BEST BUYING-GUIDE TEMPLATE

Preview: https://thesolemart.com/template-preview/buying-guide

ORDINARY WORDPRESS POSTS
You can paste a buying-guide article into a normal Post without importing a
pattern. A title such as "7 Best Curling Shoes" selects this template. Use H2
product headings such as "1. Product Name: Best for Beginners", followed by the
description, image, Pros/Cons headings and lists, and any Amazon purchase link.
Use ordinary headings for Quick picks, How we chose, FAQs and Final verdict.
The website styles the content already in your post. Missing product text and
purchase links are not invented. Add an image under each product heading to
replace the automatic placeholder. Numbered Best titles with no product headings
still get the page typography; individual product cards need product headings.

OPTIONAL ONE-TIME PATTERN SETUP
Open Manage patterns in WordPress and choose Import from JSON. Import
solemart-best-guide-pattern.json. It is an unsynced pattern: each article gets
its own independent content.

If pattern importing is unavailable, paste solemart-best-guide-pattern.html
into a new Post's Code editor, then switch back to the Visual editor.

FOR EACH ARTICLE
1. Create a normal Post and enter its title in the normal title field.
2. Insert the SoleMart — Best buying guide pattern.
3. Replace the text and images. Duplicate or remove whole product Group blocks
   as needed. Keep each product heading's HTML anchor unique; update the quick
   picks table and its links to match.
4. Edit each Buy on Amazon button's link. Add the exact product/affiliate URL.
   The blank starter points to Amazon's homepage and must be replaced. The Nike
   example opens model searches; update the small note if using direct links.
5. Save as Draft. Review, then publish when ready. The website displays published
   Posts at /blog/your-post-slug using this layout and its existing CMS cache.

Keep the Group classes included in the pattern. They tell the website which
template to use. Set the Featured Image using normal Post settings if wanted.
No custom WordPress plugin or ACF fields are needed for this Post layout.

solemart-nike-guide-example.json / .html contain the filled seven-product example.
Enter its title separately: 7 Best Nike Shoes for Men.
Photos are placeholders. Model names/versions need verification before publication.
No affiliate ID, current price, availability, test score or publication date is
invented. Future changes to the layout's CSS apply across marked articles;
editing an article's content does not change other articles.

Importing a PATTERN does not create a Post. This work does not establish automatic
draft creation or Next.js preview access for unpublished WordPress Posts.
